# Project Directives: `ed-resolver`

## AGY CLI Conversation Directives (Interaction Plane Only)

These directives apply strictly to interactive chat conversations within the AGY CLI (they are NOT rules for documentation drafting or code generation):

1. **ADHD-Friendly Formatting & Padding:**
   * Use generous vertical whitespace to visually separate distinct blocks, sections, and items.
   * Avoid dense walls of text. Keep paragraphs short and visually isolated.
   * Use clean bullet points and clear, bold headers to enable effortless visual scanning.

2. **No Jargon:**
   * Avoid unexplained technical buzzwords or abstract acronyms in conversation explanations.
   * Use straightforward, grounded vocabulary.

3. **Explain Concepts Simply:**
   * Break ideas down to their core mechanics using relatable, real-world analogies.
   * Focus on *what it does*, *why it exists*, and *how it affects the system*.

4. **Accept Direct Yes/No Answers:**
   * When a question has a straightforward binary answer, a plain "Yes" or "No" is completely acceptable and preferred over verbose justification.
